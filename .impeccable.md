## Design Context

### Users
Educational SaaS (portfolio-saas / apparchi.ru): students building an art portfolio, curators/admins/superadmins reviewing submitted work ("пробники"), scoring, and giving feedback. Used both on desktop (staff review workflows) and mobile (students checking status, uploading photos).

### Brand Personality
Calm, professional, workmanlike — a review/back-office tool, not a marketing site. One accent color (Spark blue `#3B5BFF`) used sparingly against neutral surfaces. Not playful, not maximalist; clarity and speed of task completion over visual flair.

### Aesthetic Direction
Established as "Spark Design System" (`app/static/css/base.css`), rolled out across Phases 0–4 (see `REDESIGN-PLAN.md` at workspace root). Light theme only. Manrope (display) + Figtree (body) fonts — **final, do not revisit**. Emoji used as icons throughout — **final, do not revisit**. Tokenized colors/spacing/radii/shadows/motion already defined in `:root`.

### Design Principles
1. Surgical enhancement, not rebuilds — this is Phase 5 (a11y/responsive/polish pass), not a redesign.
2. Every color/radius/duration should resolve to an existing token in `base.css`; flag ad-hoc values to the owner rather than silently inventing new tokens.
3. One accent (`--blue`) + categorical palette (`.tag-pill--*`) already covers status/category coding — don't introduce new hues.
4. WCAG AA is the bar (not AAA) — contrast, focus-visible, aria, heading hierarchy, touch targets ≥44px.
5. Icons = emoji, fonts = Manrope/Figtree — settled, out of scope to reopen.
