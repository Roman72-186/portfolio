{# Кнопка действия у задачи ученика — одна на оба экрана: вкладки недели (`cabinet_learning.html`) и «Личный трекер» (`cabinet_tracker.html`). Отдельного экрана дня больше нет — отменён решением владельца 22.08, у ученика Apparchi календаря по датам не осталось вовсе. Смысл: у задачи, к которой ведёт свой экран, ученик должен идти на этот экран, а не закрывать её галочкой. Раньше умные кнопки были только на дне, а обзор недели и трекер показывали «Отметить» на всём подряд — видео закрывалось без просмотра, пробник без сдачи. Если на такие отметки повесят доступ к следующей неделе (решение Р1), это станет обходом в одно нажатие. **Галочку убираем только там, где задача закрывается сама.** Видео (`video.py::_close_video_task_once`) и анкета (`survey_submission.py::submit_student_survey`) закрываются по своему событию. Домашка и пробник (23.08, решение владельца) закрываются либо автоматически по факту загрузки финального фото (тариф без обратной связи), либо кнопкой куратора «Принять работу»/«Закрыть цикл» (тариф с обратной связью) — в обоих случаях эта отметка была бы обходом гейта в одно нажатие, поэтому кнопка не рисуется для них вовсе. Требует в контексте: `entry` (запись из `accessible_task_entries`) и `details` (результат `program.py::item_details` — словарь по id задачи).
