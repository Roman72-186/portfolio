# Фаза 5 — UI performance hardening

Дата: 2026-07-24

## Цель

Закрыть остаточный performance-риск 3D Lab без изменения визуального языка,
контента и управления моделями.

## Найденные bottleneck

- WebGL render-loop выполнял тяжёлый рендер постоянно: в галерее, на вкладках
  схем и видео, а также при скрытой странице.
- Водяной знак создавал 506 `span`-элементов на viewport 498×698 px, включая
  состояние скрытой галереи.
- На компактных экранах renderer мог использовать pixel ratio до 2 и MSAA 4×
  для нескольких render target.

## Что изменено

- WebGL-кадр теперь пропускается, если страница скрыта, viewer не открыт или
  активна вкладка без 3D-canvas.
- Pixel ratio ограничен значением 1.5 до 768 px и 2 на больших экранах.
- MSAA render target на компактных экранах ограничен 2×; Android сохраняет
  существующий безопасный режим без MSAA.
- Водяной знак создаётся только для видимого viewer.
- Overscan водяного знака ограничен двумя плитками с каждой стороны.
- При возврате в галерею узлы водяного знака удаляются.
