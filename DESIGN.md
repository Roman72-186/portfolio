# Spark Design System

Spark — дизайн-система личного кабинета apparchi.ru. Это рабочий интерфейс для
учеников, кураторов, администраторов и суперадминистраторов. Его задача —
помогать быстро понять состояние работы и выполнить следующее действие.

Источник истины для реализации — `app/static/css/base.css`. Этот документ
объясняет назначение токенов и общих классов. Локальные стили допустимы для
уникальной компоновки экрана, но не должны заново определять общий компонент.

## Характер

- Спокойный, профессиональный, рабочий.
- Светлая тема с одним основным акцентом (фиолетовый с 28.08.2026, токен
  по-прежнему называется `--blue` — см. «Акцент кабинета» ниже).
- Чёткая иерархия важнее декоративности.
- Интерфейс работает на desktop для staff и на mobile для учеников.
- Шрифты закреплены: Manrope для заголовков, Figtree для основного текста.

## Токены

### Поверхности и текст

| Токен | Назначение |
|---|---|
| `--bg` | фон страницы |
| `--surface` | основная поверхность карточек и полей |
| `--surface-2` | вложенная или вторичная поверхность |
| `--ink` | максимально контрастные заголовки |
| `--text` | основной текст |
| `--muted` | вторичный текст |
| `--dim` | подписи, метаданные и неактивные состояния |
| `--line` | нейтральные границы |

`--dim` уже рассчитан на читаемость на светлых поверхностях. Не заменять его
случайным серым значением.

### Акцент и статусы

- `--blue` — основное действие, активный пункт, фокус.
- `--blue-deep`, `--blue-mid` — состояния брендового действия.
- `--blue-soft`, `--blue-tint`, `--blue-ink` — мягкие акцентные поверхности.
- `--success` — успешное завершение.
- `--error` — ошибка и разрушительное действие.
- `--warning-*` — предупреждение или возврат на доработку.

Новый цвет добавляется только при появлении нового устойчивого смыслового
статуса. Цвет не используется как единственный носитель значения.

### Акцент кабинета — решение 28.08.2026

Созвон 26.08 оставил основной акцент кабинета открытым вопросом («синий или
фиолетовый», расшифровка `../26082026/video1793858658_расшифровка.txt`,
00:12:41–00:14:53). 28.08 выбор сделан в пользу фиолетового и реализован:

- **`--blue` теперь фиолетовый — `#A855F7`** (тот же цвет, что и
  `.tag-pill--purple` в этом файле; ink-оттенок для текста на мягкой
  подложке — `#6B21A8`, тоже переиспользован из `.tag-pill--purple`).
  Перекликается с акцентом 3D-лаборатории, который уже подобран отдельно.
- Имя токена осталось прежним (`--blue`, `--blue-deep`, `--blue-mid`,
  `--blue-ink`, `--blue-on-soft`, `--blue-soft`, `--blue-tint`,
  `--sh-blue`) — переименование во `--purple` не делали, чтобы не менять
  236 мест использования по 28 файлам. Значения этих переменных в
  `base.css` — фиолетовая шкала (аналог Tailwind purple-400…purple-900).
- Захардкоженные дубли старого синего (`rgba(59,91,255,…)`,
  `rgba(99,126,255,…)`, `rgba(59,130,246,…)`) тоже перекрашены — они были
  разбросаны по `base.css` и ещё 9 шаблонам параллельно с токенами.

### Цвета предметов (справочно)

Не токены `base.css` — берутся из реальных обложек видео к урокам,
зафиксированы здесь для справки при работе с материалами предметов:

| Предмет | Цвет | Источник |
|---|---|---|
| Рисунок | `#3347D1` (совпадает с `--blue`) | обложки видео по рисунку |
| Композиция | `#D72A7A` | обложка видео «Врезки в конус» |

### Геометрия и ритм

- Радиусы: `--r-sm`, `--r-md`, `--r-lg`, `--r-xl`, `--r-pill`.
- Шаг отступов: `--s-1`…`--s-8`, основание 4 px.
- Тени: `--sh-sm`, `--sh-md`, `--sh-blue`.
- Движение: `--duration-fast`, `--duration-base`, `--ease-out`.

Для новых переходов используются только motion-токены. `transition: all`
не применяется: перечисляются конкретные свойства.

## Структура страницы

```html
<div class="page-header">
  <div>
    <a class="back-link" href="/cabinet">← Кабинет</a>
    <h1 class="page-title">Название экрана</h1>
    <p class="page-subtitle">Короткое объяснение задачи</p>
  </div>
  <a class="btn-blue" href="/create">Создать</a>
</div>
```

- На странице один `h1`.
- `.page-header--stacked` сохраняет вертикальную композицию без правого действия.
- `.page-title--standalone` используется, когда заголовок находится вне
  `.page-header` и ему нужен нижний отступ.
- На ширине до 480 px обычный `.page-header` складывает правое действие под
  заголовок и растягивает его на доступную ширину.
- `.section-label` обозначает компактную группу внутри экрана, но не заменяет
  смысловой `h2`, если разделу нужен заголовок документа.
- `.back-link` — единственный общий вариант ссылки «назад».

## Общие компоненты

### Карточки

- `.card` — нейтральный контейнер.
- `.card-blue` — один приоритетный блок или CTA.
- `.card-dark` — специальная контрастная поверхность.
- `.stat-tile` — числовой показатель.

Карточка не должна оборачивать каждую строку только ради визуального контейнера.
Вложенные карточки допускаются лишь при реальной иерархии данных.

### Кнопки и действия

- `.btn-blue` — основное действие.
- `.btn-outline` — вторичное или отмена.
- `.btn-danger` — разрушительное действие.
- `.btn-warn` — возврат на доработку.
- `.btn-save` — компактный модификатор сохранения.
- `.btn-full` — полноширинный модификатор.

В `.form-actions` отмена идёт первой в DOM, основное действие — последним.
На mobile порядок визуально разворачивается так, чтобы основное действие было
выше. Для модальных окон применяется `.modal-actions`.

### Формы

- Подпись: `.form-label` или `.field-label`.
- Поле: `.form-input` или `.field-input`.
- Список: `.form-select` или `.field-select`.
- Группа радио: `.radio-group` + `.radio-btn`.
- Загрузка файла: `.file-input-wrap`.

У каждого поля должна быть связанная `<label>`. Ошибка называет проблему и
способ исправления, а не только меняет цвет границы.

### Состояния

```html
<div class="empty-state">
  <div class="empty-icon" aria-hidden="true">…</div>
  <div class="empty-text">Работ пока нет</div>
</div>
```

- `.empty-state` — полноценное пустое состояние панели.
- `.empty-mini` — короткое сообщение внутри небольшой секции.
- `.alert-success` и `.alert-error` используются вместе с `.alert`.

Пустое состояние объясняет, что отсутствует. Если пользователь может исправить
ситуацию, рядом показывается конкретное действие.

### Навигация и метки

- `.nav-pill` + `.nav-pill-item` — локальная pill-навигация.
- `.seg` + `.seg-btn` — переключатель представления внутри текущего экрана.
- `.tag-pill` + семантический модификатор — компактная категория.
- `.chip` — выбранное значение или фильтр.

Pill-форма применяется только для небольших контролов и меток, не для больших
контейнеров.

### Фото

- `.photo-grid` — базовая сетка.
- `.photo-zoom-button` оборачивает интерактивную миниатюру.
- `partials/lightbox.html` — общий просмотрщик.
- У изображений должны быть `alt`, `loading="lazy"` вне первого viewport и
  зарезервированное место через размеры или `aspect-ratio`.

## Адаптивность

- До 480 px — телефон: одна колонка, полноширинные действия.
- До 768 px — mobile/tablet compact: упрощённая навигация и сетки.
- От 1024 px — desktop staff-layout и статические CTA.

Минимальная интерактивная область на touch — 44×44 px. Проверяются ширины
375, 480, 768 и 1024 px, длинные имена и реальные русские подписи.

## Доступность

- Все интерактивные элементы доступны с клавиатуры.
- Фокус не скрывается; базовый `:focus-visible` уже задан.
- Диалоги используют `role="dialog"`, `aria-modal` и возвращают фокус.
- Раскрывающиеся секции синхронизируют `aria-expanded`.
- При `prefers-reduced-motion: reduce` декоративное движение отключается.
- Контраст соответствует WCAG AA.

## Правило расширения

Перед созданием локального компонента:

1. Проверить `base.css` и этот документ.
2. Если паттерн встречается минимум три раза с одинаковым назначением —
   извлечь общий класс.
3. Если назначение отличается, оставить локальную реализацию.
4. После изменения общего CSS увеличить `?v=` в `base.html`.
5. Проверить desktop, mobile, клавиатуру и reduced motion.

Пункты выше — намерение. Держит его тест `tests/test_reuse_ratchet.py`: он
запрещает **рост** инлайнового CSS, цветов числом и переопределений общих
классов, сверяясь со срезом `tests/reuse_baseline.json`. Текущее состояние
законно, новое — нет. Стилей стало меньше — зафиксировать:
`python scripts/reuse_check.py --update`.

Порядок работы, карта готовых компонентов и правила сборки кабинетов ролей — в
`../docs/reuse-contract.md` и `../docs/component-map.md`.
