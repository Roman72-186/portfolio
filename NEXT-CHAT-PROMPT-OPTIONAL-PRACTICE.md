## Исходная реализация и проверка

Запрос: в «Ученики поимённо → Практика → месяц → цикл» дополнительные
задания без блокировки не должны мешать закрытию недели. Видео-референс:
`../10.11/video.mp4`; просмотрен кадр на 8-й секунде.

Причина: `cycleSummary` в `app/templates/partials/students_by_name.html`
считала все `eligible` работы. Сервис `app/services/staff_dashboard.py`
теперь отдаёт `required` для каждого блока: общая политика
`required_by_block_for_task`, `get_required_tariffs`, исключение скрытых до
сдачи блоков. В практике итог недели/месяца считает только обязательные
этому ученику работы. Детализация дополнительной работы, её фактические
сдачи, баллы, теория и занятия сохраняют прежнее поведение.

Регрессия воспроизведена до исправления: обязательная работа сдана,
дополнительная пропущена; JS возвращал total=2, missing=['Extra'].
Тесты добавлены в существующий `tests/test_students_by_name.py`.

Проверки после правки: 106 passed (17 предупреждений устаревших API).
